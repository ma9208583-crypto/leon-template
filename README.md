# قالب ليون (Leon Template)

## نبذة عن المشروع
مشروع Leon هو صفحة ويب بسيطة تهدف إلى عرض نموذج لموقع وكالة إبداعية، حيث تقدم الصفحة نبذة عن الخدمات والأعمال والمميزات التي توفرها الوكالة، بالإضافة إلى معلومات التواصل.

تم إنشاء الصفحة باستخدام لغة HTML لتنظيم محتوى الموقع وتقسيمه إلى أقسام واضحة ومنظمة.

## شرح الكود
يتكون ملف `index.html` من مجموعة من الأقسام الرئيسية، وهي:

- **Header:** يحتوي على شعار الموقع وقائمة التنقل التي تساعد المستخدم على الانتقال بين أقسام الصفحة.
- **Landing:** القسم الرئيسي الذي يعرض عنوان الموقع ونبذة تعريفية عنه مع صورة.
- **Features:** يعرض مجموعة من مميزات الموقع.
- **Services:** يحتوي على الخدمات التي تقدمها الوكالة، مع أيقونات وصورة توضيحية.
- **Portfolio:** يعرض مجموعة من الأعمال والمشاريع مع صور ووصف لكل مشروع.
- **About:** يقدم نبذة تعريفية عن الوكالة.
- **Contact:** يحتوي على معلومات التواصل وروابط وسائل التواصل الاجتماعي.

تم تنظيم الكود باستخدام عناصر HTML وتقسيم الصفحة إلى أجزاء مستقلة، مع استخدام التعليقات (Comments) لتوضيح الأقسام المختلفة وتسهيل قراءة الكود وفهمه.
